## Featured project

**[SEC correspondence: research data and timing](https://github.com/bosstraitod-cell/sec-correspondence-research)**

This is a small, runnable part of my thesis. It shows how I handle historical index
membership, private filing dates, public release dates and weekly volatility.
You can try it offline with the included examples and tests.

2006–2025. Contextual NLP/LLM validation and mutual-information and volatility-regime
estimation remain research in progress.
